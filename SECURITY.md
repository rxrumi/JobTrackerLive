# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through this repository's GitHub
**Security** tab using **Report a vulnerability**. Do not disclose security
issues in public issues, pull requests, discussions, social media, or job data.

Include the affected route or component, impact, reproduction steps, and any
safe proof of concept. Do not access another user's data, run destructive
tests, disrupt the production service, or retain personal information while
investigating.

The owner will acknowledge a valid report when practicable, investigate it,
and coordinate disclosure after a fix is available. No guaranteed response or
remediation timeline is offered.

## Supported version

Only the version currently deployed from the protected `master` branch is
supported. Forks, copied code, and independent deployments are neither
licensed nor supported.

## Scope

The policy covers original code in this repository and the production Live Job
Index service. Vulnerabilities in Clerk, Cloudflare, OpenAI, public applicant
tracking systems, or other third-party services should also be reported to the
relevant provider.
